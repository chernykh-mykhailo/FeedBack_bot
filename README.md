# 🤖 Advanced Telegram Feedback Bot

🇺🇦 **Професійний бот для зворотного зв'язку в Telegram**, розроблений на `aiogram 3.x`. Бот перетворює вашу групу на повноцінну систему підтримки, створюючи окремі топіки (форумні гілки) для кожного користувача.

## ✨ Особливості

- 📁 **Topic-based Support**: Кожен новий користувач отримує власну гілку обговорення в адмін-групі.
- 🔄 **Двостороння синхронізація реакцій**: Якщо адмін ставить реакцію на повідомлення — користувач її бачить, і навпаки.
- 🎁 **Повна кастомізація**: Через адмін-панель можна налаштувати:
  - Привітальне повідомлення (Start Message) з підтримкою HTML та ключових слів.
  - Шаблон імені топіка (Topic Name).
  - Анонімний режим (Anonymous Mode).
- 📊 **Статистика**: Перегляд загальної кількості користувачів та повідомлень.
- 🛠️ **Легке налаштування**: Підключення адмін-групи одним натисканням кнопки через `request_chat`.
- 💾 **Надійність**: Використання `aiosqlite` для асинхронної роботи з базою даних.

## 🚀 Швидкий запуск

### 1. Підготовка
Вам знадобиться:
- Python 3.10+
- Токен бота від [@BotFather](https://t.me/BotFather)
- Група в Telegram з увімкненими **Topics** (форум).

### 2. Встановлення
```bash
git clone https://github.com/chernykh-mykhailo/FeedBack_bot.git
cd FeedBack_bot
pip install -r requirements.txt
```

### 3. Налаштування (.env)
Створіть файл `.env` у корені проекту:
```env
BOT_TOKEN=your_bot_token_here
ADMIN_GROUP_ID=0  # Залиште 0, бот запропонує налаштувати групу при запуску
```

### 4. Запуск
```bash
python bot.py
```

## 🛠 Команди адміна
- `/admin` — Відкриває панель керування ботом (тільки в приватних повідомленнях).
- `/setup` — (автоматично при першому запуску) допомагає вибрати групу для звернень.

## 📝 Ключові слова для тексту
Ви можете використовувати ці теги в привітальному повідомленні або назві топіка:
- `#FIRST_NAME` — Ім'я користувача
- `#LAST_NAME` — Прізвище
- `#USERNAME` — Юзернейм (@username)
- `#USER_ID` — ID користувача
- `#MENTION_USER` — Клікабельне згадування (тільки для повідомлень)

## 🏗 Стек технологій
- **Framework**: [aiogram 3.x](https://docs.aiogram.dev/)
- **Database**: [aiosqlite](https://github.com/omnilib/aiosqlite)
- **Config**: [pydantic-settings](https://docs.pydantic.dev/latest/usage/pydantic_settings/)
- **Logging**: Стандартний logging Python
